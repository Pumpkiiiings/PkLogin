## Changing the language

<Steps>

<Step>
Install the plugin and start the server once so the files are generated.
</Step>

<Step>

Set `languageFile` in `config.yml` to the file you want:

```yaml title="config.yml"
languageFile: 'messages_es.yml'
```

</Step>

<Step>
Run `/pklogin reload`, then edit the message file to taste.
</Step>

</Steps>

## Customising messages

Edit the file named by `languageFile` directly. Messages are plain YAML and support the
usual colour codes:

```yaml title="messages_en.yml"
messages:
  before-login:
    subtitle: '&7Use: /login <password>'
```

## Where messages appear

Two switches control the on-screen surfaces:

```yaml title="config.yml"
ui:
  # Title-bar messages.
  use-title-bar: true

  # Action-bar messages.
  use-action-bar: true
```

## Contributing a translation

Copy `messages_en.yml`, translate the values, and open a pull request with the file named
for its language code. Keys are shared across every file, so a missing key falls back to
nothing rather than to English — translate them all.
