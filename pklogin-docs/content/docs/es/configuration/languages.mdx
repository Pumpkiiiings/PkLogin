## Cambiar el idioma

<Steps>

<Step>
Instala el plugin y arranca el servidor una vez para que se generen los archivos.
</Step>

<Step>

Fija `languageFile` en `config.yml` al archivo que quieras:

```yaml title="config.yml"
languageFile: 'messages_es.yml'
```

</Step>

<Step>
Ejecuta `/pklogin reload` y edita el archivo de mensajes a tu gusto.
</Step>

</Steps>

## Personalizar mensajes

Edita directamente el archivo que nombra `languageFile`. Los mensajes son YAML plano y
soportan los códigos de color habituales:

```yaml title="messages_es.yml"
messages:
  before-login:
    subtitle: '&7Usa: /login <contraseña>'
```

## Dónde aparecen los mensajes

Dos interruptores controlan las superficies en pantalla:

```yaml title="config.yml"
ui:
  # Mensajes en la barra de título.
  use-title-bar: true

  # Mensajes en la action bar.
  use-action-bar: true
```

## Contribuir una traducción

Copia `messages_en.yml`, traduce los valores y abre un pull request con el archivo nombrado
por su código de idioma. Las claves son comunes a todos los archivos, así que una clave que
falte cae a nada en vez de al inglés: tradúcelas todas.
