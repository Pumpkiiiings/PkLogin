---
title: Installation
description: Install PkLogin on a standalone Paper, Spigot or Folia server.
---

This page covers a single server with no proxy in front of it. If your network runs
Velocity, read [Velocity setup](/en/docs/getting-started/velocity) instead — the steps
differ and the proxy has to be installed first.

## Requirements

- **Java 21** or newer
- **Paper, Spigot or Folia** on API level 1.20 or newer

## Steps

<Steps>

<Step>

### Download the jar

Grab `PkLogin.jar` from the [releases page](https://github.com/Pumpkiiiings/PkLogin/releases)
and drop it into your server's `plugins/` folder.

</Step>

<Step>

### Turn off online mode

```properties title="server.properties"
online-mode=false
```

With `online-mode=true` the server authenticates every player against Mojang itself, and no
cracked player can join — which leaves PkLogin nothing to do.

<Callout type="warn" title="Firewall the port">
  An offline-mode server accepts any name a client claims. Do not expose the game port to
  the internet without knowing what reaches it.
</Callout>

</Step>

<Step>

### Start the server

Configuration files are generated on first start:

<Files>
  <Folder name="plugins/PkLogin" defaultOpen>
    <File name="config.yml" />
    <File name="messages_en.yml" />
    <Folder name="2fa">
      <File name="discord.yml" />
    </Folder>
    <File name="accounts.db" />
  </Folder>
</Files>

</Step>

<Step>

### Edit and reload

Open `plugins/PkLogin/config.yml`, change what you need, then run:

```
/pklogin reload
```

Reload re-reads `config.yml` and the message file. Changing the **database engine** still
needs a full restart.

</Step>

</Steps>

## Verifying it works

Join the server with a cracked client. You should be frozen in place and asked to register:

```
/register <password> <password>
```

Then join with a premium account whose name PkLogin has never seen. With
`autologin.premium.enable` on, you should be logged in without typing anything.

## Common first-run problems

<Accordions>

<Accordion title="Premium players are asked to register">

Either `autologin.premium.enable` is `false`, or the name already exists in the database
as an offline account. An existing offline account is
converted with `/premium confirm` — PkLogin never changes the mode of an account it already
knows.

</Accordion>

<Accordion title="Everyone joins without logging in">

`online-mode` is still `true` in `server.properties`, so the server authenticated everyone
against Mojang before PkLogin was reached.

</Accordion>

<Accordion title="Players are kicked after 45 seconds">

That is `Security.time-to-login`, the window to run `/login` or `/register`. Raise it if
your join flow needs longer.

</Accordion>

</Accordions>
