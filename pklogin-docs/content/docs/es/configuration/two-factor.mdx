---
title: Autenticación en dos pasos
description: 2FA por Discord — cómo se vincula, cómo se configura el bot y las opciones de los códigos.
---

El 2FA por Discord vincula una cuenta de Minecraft con una de Discord usando un bot que
escribe por MD. Una vez vinculadas, al jugador le llega un código cada vez que se loguea.

<Callout type="warn" title="Discord es el único proveedor conectado al login">
  El 2FA por email viene en el plugin pero todavía no está conectado al login, y el TOTP
  necesita el módulo de Forge, que no está en este repositorio. Los dos quedaron anotados como
  trabajo pendiente.
</Callout>

## Cómo se vincula

<Steps>

<Step>
El jugador escribe `/2fa discord` en el juego y le sale un código de 6 dígitos.
</Step>

<Step>
Le manda ese código al bot por mensaje directo en Discord.
</Step>

<Step>
Las cuentas quedan vinculadas. De ahí en adelante, cada login le manda un código nuevo a ese
MD.
</Step>

</Steps>

El jugador escribe el código que le llegó con:

```
/2fa verify2fa <código>
```

## Configuración del bot

```yaml title="plugins/PkLogin/2fa/discord.yml"
enable: false

authentication:
  # El token que saques del portal de desarrolladores de Discord.
  token: ""

options:
  link-required:
    # Exigir tener Discord vinculado para poder autenticarse.
    enable: false
    # Exigírselo también a los jugadores premium.
    required-for-premium: true

  # Cuántas cuentas de Minecraft pueden compartir una misma cuenta de Discord.
  account-limit: 1

  # Recomendarles que vinculen a los que todavía no lo hicieron.
  recommend-linking: true

  # Pedir una contraseña nueva después de recuperar la cuenta. Si está
  # desactivado, le pone una al azar.
  force-password-update: false

  # El link de invitación a tu servidor de Discord. Sin esto no se puede
  # completar una vinculación.
  invite-url: "SERVER INVITATION"

  # El mensaje de estado del bot.
  presence: ""
```

<Callout type="warn" title="invite-url no es un adorno">
  Sin eso no se puede completar ninguna vinculación: el jugador tiene que poder entrar al
  servidor donde está el bot.
</Callout>

## Opciones de los códigos

Están en el config principal y valen para todos los proveedores:

```yaml title="config.yml"
two-factor:
  # Dígitos que tiene cada código. De 4 a 9.
  code-length: 6

  # Segundos que sigue valiendo un código de login.
  login-code-expiration: 300

  # Segundos que sigue valiendo un código de vinculación.
  link-code-expiration: 600

  # Códigos errados que se permiten antes de tirar abajo el código pendiente y
  # obligar al jugador a loguearse de nuevo.
  max-verify-attempts: 5

  discord:
    # Códigos de vinculación que un mismo usuario de Discord puede probar por
    # ventana, para que nadie se recorra todos los códigos posibles
    # escribiéndole al bot.
    max-link-attempts: 10
    # Cuánto dura esa ventana, en segundos.
    link-attempt-window: 600
```

Los códigos son de un solo uso.

## Cómo se lleva con las sesiones

Activarle o desactivarle el 2FA a una cuenta tira abajo la [sesión de
login](/es/docs/configuration/sessions) que tenga abierta. Y ojo con el otro lado: mientras
esa sesión está abierta, quien se reconecte desde la misma IP se saltea **tanto** la
contraseña como el código 2FA. Deja `Security.session.timeout` bien corto si esperas que el
2FA proteja algo.
