## Cambiar el idioma

<Steps>

<Step>
Instala el plugin y arranca el servidor una vez para que se creen los archivos.
</Step>

<Step>

Ponle a `languageFile` en `config.yml` el archivo que quieras:

```yaml title="config.yml"
languageFile: 'messages_es.yml'
```

</Step>

<Step>
Ejecuta `/pklogin reload` y edita el archivo de mensajes a tu gusto.
</Step>

</Steps>

## Editar los mensajes

Edita directo el archivo que pusiste en `languageFile`. Los mensajes son YAML común y
soportan los códigos de color de siempre:

```yaml title="messages_es.yml"
messages:
  before-login:
    subtitle: '&7Usa: /login <contraseña>'
```

## Dónde se muestran los mensajes

Hay dos opciones para elegir dónde aparecen en pantalla:

```yaml title="config.yml"
ui:
  # Mensajes en el título.
  use-title-bar: true

  # Mensajes en la action bar.
  use-action-bar: true
```

## Aportar una traducción

Copia `messages_en.yml`, traduce los valores y abre un pull request con el archivo nombrado
con su código de idioma. Las claves son las mismas en todos los archivos, así que una clave
que falte no muestra nada — no cae al inglés. Tradúcelas todas.
