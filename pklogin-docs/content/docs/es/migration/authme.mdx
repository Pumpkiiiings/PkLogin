---
title: Importar desde AuthMe
description: Pasa todas las cuentas de AuthMe a PkLogin con un solo comando.
---

<Steps>

<Step>

### Deja la base de datos de AuthMe a mano

Pon `authme.db` en `plugins/AuthMe/authme.db`, o dile a PkLogin dónde está:

```yaml title="config.yml"
authme-import:
  # Ruta absoluta a authme.db. Vacío usa plugins/AuthMe/authme.db.
  database-path: ""
```

</Step>

<Step>

### Ejecuta la importación

```
/pklogin authme-import
```

Corre en segundo plano y avisa del progreso cada 100 cuentas.

</Step>

<Step>

### Saca AuthMe

Cuando te avise de que terminó, baja el servidor y borra el jar de AuthMe. Dos plugins de
login peleándose por los mismos eventos no termina bien.

</Step>

</Steps>

## Qué se guarda

| Dato | Notas |
| --- | --- |
| Contraseña | Entra como hash AuthMe SHA256, en solo lectura. Se pasa sola a tu algoritmo configurado en el primer login del jugador. |
| IP | Se guarda, así que el límite por IP y `/pklogin dupeip` funcionan desde el día uno. |
| Fecha de registro | Se guarda. |

## Lo puedes correr las veces que quieras

Las cuentas que ya importaste se saltean, así que ejecutar el comando otra vez solo te cuesta
el tiempo que tarda.

## Las contraseñas después de importar

AuthMe SHA256 solo sirve para **leer**. PkLogin nunca guarda un hash nuevo en ese formato: la
primera vez que un jugador importado se loguea bien, la contraseña se vuelve a hashear sola
con lo que tengas en `Security.hash-algorithm`. Nadie tiene que resetear nada.

Mira [Seguridad de contraseñas](/es/docs/configuration/security) para ver la lista de
algoritmos.
